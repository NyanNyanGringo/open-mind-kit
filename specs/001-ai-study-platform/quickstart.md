# Quickstart: AI Study Platform

**Branch**: `001-ai-study-platform` | **Date**: 2026-02-18

Этот документ описывает, как развернуть и запустить приложение локально,
а затем пройти сквозной сценарий — от загрузки файлов до первой карточной сессии.

---

## Prerequisites

| Инструмент | Минимальная версия | Проверка |
|------------|-------------------|---------|
| Docker Desktop | 4.x | `docker --version` |
| Docker Compose | 2.x | `docker compose version` |
| Git | any | `git --version` |
| Свободная RAM | 4 GB+ | — |
| Свободное место | 10 GB+ | — |

Для faster-whisper (транскрипция) дополнительно нужен **ffmpeg** в системе:
- macOS: `brew install ffmpeg`
- Ubuntu/Debian: `sudo apt install ffmpeg`
- Windows: установить через winget или скачать с ffmpeg.org

---

## Шаг 1: Клонировать репозиторий

```bash
git clone https://github.com/<org>/study-kit.git
cd study-kit
```

---

## Шаг 2: Создать файл конфигурации

```bash
cp .env.example .env
```

Открыть `.env` и проверить значения по умолчанию. Изменять обязательно нужно только:

```dotenv
# Секретный ключ для шифрования токенов (сгенерировать случайный)
SECRET_KEY=замените_на_случайную_строку_минимум_32_символа

# Максимальный размер загружаемого файла (в байтах, по умолчанию 500 МБ)
MAX_FILE_SIZE_BYTES=524288000

# Модель Whisper для транскрипции (large-v3-turbo | medium | small)
WHISPER_MODEL=large-v3-turbo
```

---

## Шаг 3: Запустить приложение

```bash
docker compose up --build
```

При первом запуске Docker скачает образы и загрузит модель Whisper (~1.5 GB).
Последующие запуски значительно быстрее.

После появления строки `Application startup complete` открыть браузер:

```
http://localhost:3000
```

---

## Шаг 4: Подключить AI-агента

После открытия браузера откроется onboarding-экран. Нужно подключить хотя бы одного провайдера.

### Вариант A — Anthropic (Claude)

1. Открыть `platform.anthropic.com/settings/keys`
2. Создать новый API-ключ
3. Вернуться в приложение → **Settings → AI Agent → Anthropic**
4. Вставить ключ (`sk-ant-...`) → нажать **Подключить**
5. Статус изменится на `connected ✓`

### Вариант B — OpenAI (Codex)

1. В приложении → **Settings → AI Agent → OpenAI**
2. Нажать **Авторизовать через OAuth2**
3. Откроется браузерная вкладка с экраном авторизации OpenAI
4. Разрешить доступ → вкладка закроется автоматически
5. Статус изменится на `connected ✓`

---

## Шаг 5: Создать рабочее пространство

1. На главном экране → кнопка **Новое пространство**
2. Ввести название (например, «Сербский язык») → **Создать**
3. Пространство появится в списке

---

## Шаг 6: Создать урок и загрузить файлы

1. Открыть рабочее пространство → **Новый урок** → «Урок 1 — Приветствия»
2. Открыть урок → перетащить файлы в область загрузки или нажать **Выбрать файлы**
3. Поддерживаемые форматы: PDF, PPTX, PPT, DOCX, DOC, TXT, MD, MP3, MP4, MOV, WAV, M4A, PNG, JPG, JPEG, WEBP
4. Каждый файл получает статус обработки:
   - `В очереди` → `Обрабатывается` → `Готово ✓`
   - При ошибке: `Ошибка ✗` с описанием причины
5. После завершения обработки в уроке появятся извлечённые элементы знания

---

## Шаг 7: Запустить первую карточную сессию

1. Из урока или с главного экрана → кнопка **Начать сессию**
2. Выбрать уроки (один или несколько)
3. Выбрать режим: **Все элементы** / **Слабые места** / **Только новые**
4. Нажать **Старт**
5. На каждой карточке нажать одну из кнопок:
   - **Again** (1) — совсем не знаю
   - **Hard** (2) — с большим трудом
   - **Good** (3) — правильно
   - **Easy** (4) — очень легко
6. По завершении сессии — экран с результатами и кнопкой **Повторить слабые**

---

## Шаг 8: Посмотреть дашборд

Иконка графика в навигации → **Дашборд**:
- Общий прогресс: сколько элементов изучено
- График сессий по дням
- Список слабых элементов (mastery score < 70%)
- Фильтрация по рабочему пространству

## Остановка и перезапуск

```bash
# Остановить (данные сохраняются в Docker volumes)
docker compose down

# Перезапустить
docker compose up

# Полный сброс (УДАЛЯЕТ ВСЕ ДАННЫЕ)
docker compose down -v
```

## Структура данных на диске

```
~/.config/study-kit/
├── credentials.json.enc   # Зашифрованные OAuth-токены / API-ключи
└── .salt                  # Соль для PBKDF2 (не удалять)

# Внутри Docker volume:
/data/
├── app.db                 # SQLite база данных
├── uploads/               # Загруженные файлы
└── processed/             # Обработанный контент
```

## Устранение типичных проблем

| Симптом | Вероятная причина | Решение |
|---------|------------------|---------|
| Файл завис в статусе "Обрабатывается" | ARQ worker упал | `docker compose restart worker` |
| "Агент недоступен" при старте сессии | Токен устарел | Settings → переподключить агента |
| Транскрипция очень медленная | Нет GPU, модель large | Сменить `WHISPER_MODEL=medium` в `.env` |
| Ошибка "unsupported format" для .ppt | Нет LibreOffice в контейнере | Конвертировать в .pptx перед загрузкой |
| `docker compose up` падает с OOM | Модель Whisper требует RAM | Установить `WHISPER_MODEL=small` |
